# Healthcare IAM Lab

## Project Overview

This project demonstrates the implementation of a hybrid Identity and Access Management (IAM) environment using:

- Windows Server 2025
- Active Directory Domain Services (AD DS)
- Microsoft Entra ID
- Microsoft Entra Connect
- VMware Workstation

## Objectives

- Configure Active Directory Domain Services
- Create Organizational Units (OUs)
- Manage Users and Security Groups
- Implement Role-Based Access Control (RBAC)
- Configure Microsoft Entra Connect
- Implement Password Hash Synchronization (PHS)
- Synchronize identities between on-premises AD and Microsoft Entra ID

## Lab Environment

- Windows Server 2025
- VMware Workstation
- Active Directory Domain Services
- Microsoft Entra ID
- Microsoft Entra Connect

## Tasks Performed

### Active Directory Administration

- Installed and configured Windows Server 2025
- Promoted server to Domain Controller
- Created Organizational Units (OUs)
- Created and managed user accounts
- Configured security groups
- Applied Group Policy basics

### Identity and Access Management

- User Provisioning
- User Deprovisioning
- Password Management
- Role-Based Access Control (RBAC)
- Account Administration

### Hybrid Identity Integration

- Installed Microsoft Entra Connect
- Configured Password Hash Synchronization
- Verified user synchronization
- Managed identities in Microsoft Entra ID
